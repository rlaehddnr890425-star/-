# Neuroa UI 목업 (와이어프레임)

> **Neuroa** — AI가 일하는 동안, 당신은 수익을 얻습니다.
>
> 유튜브처럼 소비자가 직접 브라우징하고, 모든 AI 플랫폼이 API로 참조하는 완전 개방형 매칭 네트워크.

## 2. 콘텐츠 상세 + AI 동행 시청 ⭐ (핵심 차별점)

기존 유튜브·틱톡에 없는 기능: 영상 옆에 Neuroa 내장 AI 채팅창이 상시 열림.
유저가 AI 모델 선택 → Neuroa가 백엔드 API로 처리 (Claude / GPT / Gemini).
유저는 별도 AI 구독 불필요.

```
┌──────────────────────────────────────────────────────────────────┐

├────────────────────────────────┬─────────────────────────────────┤

│                                │                                │

│   조회 12,341 · 좋아요 284     │    배터리는 ASUS가 우위에요.   │
```

## 3. 내 AI 대시보드 ⭐ (개인화 학습 허브)

좋아요·댓글·시청 이력·AI 대화 내용을 모두 학습해 초개인화 추천 제공.
외부 AI(ChatGPT·Claude·Gemini)와 연결하면 그 대화에서도 Neuroa 프로파일 참조.

```
┌──────────────────────────────────────────────────────────────────┐
│ 🤖 내 AI 프로파일                                                 │
├──────────────────────────────────────────────────────────────────┤
│  학습 현황                                                        │
│  시청 284편 · 좋아요 89개 · AI 대화 1,241턴 · 실구매 12건        │
│                                                                  │
│  내 AI가 파악한 관심사                                            │
│  [휴대용 전자기기] [프리미엄 가성비] [개발자 도구] [× 수정]      │
│                                                                  │
│  외부 AI 연결 (이 프로파일을 공유할 AI 선택)                      │
│  ☑ ChatGPT  ☑ Claude  ☑ Gemini  ☐ Perplexity                   │
│  → 연결된 AI와 대화 시 Neuroa 프로파일 자동 참조                 │
│                                                                  │
│  Zero-Click 등록 예시 (다른 AI 플랫폼에서)                       │
│  ─────────────────────────────────────────                      │
│  제조업 대표: "제품 홍보 방법 찾고 있어요"                        │
│  Claude:     "Neuroa에 등록하시겠어요?                           │
│               Google 계정으로 10초 가입 후                       │
│               지금 대화 내용으로 상품 자동 등록됩니다."           │
│  대표: "네"  →  자동 등록 완료 + 쿠팡·AI 매칭 시작              │
│                                                                  │
│  [전체 데이터 다운로드] [학습 초기화] [AI 연결 끊기]              │
└──────────────────────────────────────────────────────────────────┘
```
